Limits & report format

Each input is limited to 200 units and 6,000 UTF-16 code units (some characters use two). Word mode ignores whitespace and keeps punctuation attached. Line mode normalizes CRLF and CR to LF; blank lines and a trailing newline count as units. No uploads, persistence, AI rewriting or external services.

Report lines begin with = unchanged, − removed (ASCII - in report), or + added. Each unit is encoded as a JSON string, preserving empty units and escaping tabs and backslashes. Clipboard access may be denied; select the report and use your browser copy command. The gallery supplies the separate recipe download.
