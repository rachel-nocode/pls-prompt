## Ordered build and repair record

1. Implement the shared offline, inline-only, sandbox-compatible contract and all five concrete specifications. `build_demos.py` is the source generator for the final standalone HTML artifacts.
2. Run initial Chrome checks in an opaque-origin `sandbox="allow-scripts"` srcdoc iframe with the exact required CSP. Tempo Lab passed. Studio Desk's native form submission was blocked before its submit listener because `allow-forms` was absent.
3. Repair Studio Desk and Orbit Notes: replace submit buttons with `type="button"`, invoke explicit save functions, use `reportValidity`, and handle Enter in single-line fields by preventing default and invoking the same save function. Do not add sandbox permissions.
4. Rerun all five functional checks successfully and inspect desktop/320px screenshots. Correct the validation harness's iframe screenshot height to capture Studio Desk's long mobile page; this was a harness repair, not a product blank-screen defect.
5. Improve narrow-screen interactions: add Tempo Lab's native Track/Step selectors and Toggle step control; keep Pixel Garden's mobile wordmark on one line. Record these refinements in the individual recipes.
6. Run final Chrome functional, 320px overflow and emulated-touch checks against the final files. All five pass with zero console errors and zero observed network requests. Preserve validation results, test code and screenshots.
7. Write consolidated prompts to `.prompt.txt`, ordered per-demo records to `.recipe.md`, and the machine-readable prompt/asset manifest to `demo-manifest.json`. These recipes reflect the implementation; they are not evidence of a second independent build.
