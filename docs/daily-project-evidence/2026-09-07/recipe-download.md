# Glyph Loom

Draw one tile. Watch it become a repeating pattern.

Recipe version: daily-glyph-loom-v1
Tool: Codex · GPT-6 Astra (High)

## Before you start

Open an empty folder in Codex, paste Step 1, then Step 2 in the same task. Open glyph-loom.html in a modern browser or serve it with a static server. No packages, credentials, paid services or assets are needed. The PLS PROMPT gallery supplies separate host chrome and recipe download.

## 1. Build Glyph Loom

Build a complete standalone glyph-loom.html with inline CSS and JavaScript. It is a 16-by-16 binary pixel-pattern editor with mirrored drawing, a live 3-by-3 repeat preview and selectable ASCII output. No packages, external assets, network, storage, accounts, audio, eval or form submission. Include a viewport meta and CSP meta exactly: default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data:; connect-src 'none'. It must work in iframe sandbox='allow-scripts' with opaque origin. After synchronous initialization send window.parent.postMessage({type:'pls-demo-ready'}, '*').

Design an original near-black printmaking instrument: canvas #080808, panels #111111, gray hairline borders #383838, text #f2f2f2 and secondary #b8b8b8. Large condensed system sans uppercase GLYPH LOOM heading; system monospace for labels and controls. Subtitle: Draw one tile. Watch it become a pattern. Header includes 16 x 16 / PATTERN WORKSHOP. Desktop uses two equal-width panels, editor left and repeated cloth preview right, with a restrained ASCII +---+ divider motif, generous padding, rounded 12px panel corners and a bottom output section. Below 700px stack editor, repeat preview and output. Colored pixels are the only accent; controls remain grayscale. Use Mint #a8ebcb initially, Amber #edc583 and Violet #c7b6ef palette options. Active ink uses the selected color; empty pixels use #111111. Color changes affect only preview, never binary data or ASCII. Use clear selected states, 44px minimum ordinary controls, 16px body type, focus outline, normal wrapping, no forced motion and no horizontal page overflow at 320px or 200% root text.

Store a row-major array of exactly 256 zeros/ones in session memory. Initial Diamond preset uses zero-based x,y: 5 <= abs(x-7.5)+abs(y-7.5) <= 7. Steps preset: (floor(x/2)+floor(y/2))%4===0. Orbit preset: 25 <= (x-7.5)^2+(y-7.5)^2 <= 42. Each preset replaces the tile as one undoable action, leaving tool/mirror/palette unchanged. Presets are deterministic.

Editor: square canvas with internal resolution 512x512 and 16x16 cells, thin grid lines, and a visible cursor outline with non-color corner marks. Keep CSS aspect ratio 1. Make canvas focusable with role=application and an accessible name explaining keyboard use; keep instructions visible outside. Show current one-based row/column and count of inked cells. Start cursor at row 1 column 1. Ink brush sets cells to 1; Erase sets to 0, never toggle. Mirror mode initially Both axes; other modes None and Left/right. Left/right stamps (x,y) and (15-x,y). Both axes also stamps (x,15-y) and (15-x,15-y); deduplicate positions. Changing mirror mode affects future marks only.

Mouse/pen/touch drawing: pointerdown on editor starts one stroke and focuses editor; map client coordinates via its bounding box, clamp 0..15, capture pointer. Accept only primary pointer and primary button. On pointermove during the same captured pointer, interpolate skipped cells with integer Bresenham line, applying current ink/erase and mirror mode. On pointerup, pointercancel or lostpointercapture finish the stroke as ONE undoable action if tile changed; handle termination idempotently. Hover may update cursor but does not draw. Keep touch-action:none scoped to the drawing canvas; page elsewhere scrolls. Never lose completed marks on pointer exit. Show live preview/count/output during drawing. Before any other state-changing control action finalize any active stroke.

Keyboard when editor focused: Arrow keys move cursor one cell and clamp at edges, Home moves column to 1, End to 16; prevent default only handled keys. Space or Enter stamps at cursor as one undoable action, retains canvas focus. Provide equivalent labeled Row and Column number inputs (1..16, initially 1), and a Stamp cell button using the same tool and mirror rules; reject empty/noninteger/out-of-range values with a visible status, no drawing or history change. Arrow movement and pointer movement keep those coordinate inputs synchronized. No global shortcut handler that intercepts text editing.

Undo and Redo restore whole tile snapshots; maximum 50 previous actions, clear redo after a new changed action. Disable unavailable controls. No-op stamps/presets/clear produce no history entry. Clear tile zeros all cells; Invert tile swaps 0/1; each is undoable. Reset workshop restores original Diamond, Ink, Both axes, Mint, cursor 1/1, empty history and redo. Settings/cursor changes alone are not undo entries. Undo/redo restore tile only, preserving settings. Show polite live status with action outcome (not every pointermove).

Repeat preview is another square canvas of internal size 768x768, drawing the same tile repeated 3 times horizontally and vertically (48x48 cells). No editing or grid lines in repeat preview; give it an image role and meaningful accessible name. Label it 3 x 3 REPEAT with dynamic ink count and coverage percent rounded to nearest whole percent. Update both canvases on tile or palette change. Use crisp integer canvas rects.

Output: labeled read-only textarea containing exactly 16 lines of 16 characters each, # for ink and . for empty, no trailing newline. Update after every tile change. Add Select ASCII to focus/select the complete output for manual copying, plus Copy ASCII that attempts navigator.clipboard.writeText and then document.execCommand('copy') if necessary. Confirm Copied only on success; otherwise say Copy unavailable. Use Select ASCII and your browser copy command. Guard missing APIs; clipboard denial must never break drawing. No file-download action inside this sandbox. The host distributes the recipe separately. Display: Session only. Reload clears edits. ASCII is a tile, not an image file. This is a drawing tool, not AI generation. Use inert textContent/value for text. All displayed metrics must derive from tile state.

## 2. Verify and repair

Run the finished HTML in a browser inside an iframe with sandbox='allow-scripts'. Verify readiness message comes from opaque origin null, no external requests and no script errors. Check all three presets against their supplied formulas, 256-cell state, 16x16 #/. output, and matching preview. Clear; stamp row 2 column 3 with Both axes -> exactly (2,3),(2,14),(15,3),(15,14) in one-based coordinates; repeat stamp is a no-op; Undo clears all four; Redo restores. Change mode to None, erase one cell -> count 3; undo restores 4. Clear again; pointer drag must fill skipped cells with Bresenham and undo as one action; exercise touch and pointer termination. Verify Left/right, keyboard edge clamping and Space/Enter, coordinate validation (empty, 0, 17, fractional), no-op history, redo invalidation and 50-entry history cap. Invert twice restores exact output. Palette change leaves ASCII unchanged. Reset restores every initial setting and clears history. Test copy success and denial separately; Select ASCII must select full output. Inspect widths 320,375,768,1024,1440,1600 and 200% root text; repair overflow, clipped controls, canvas distortion or unreadable text. Check dynamic metrics and repeat rendering. Capture real screenshots of the running editor and a changed pattern. Rebuild separately from this pack in an empty directory and run the same behavioral checks. Record actual model, interventions, test coverage and reproduction result; do not claim unrun browser or independent-user coverage. Preserve the no-network, opaque-origin, session-memory design.

## Make it yours

Change the three preset formulas or ink palettes. Keep formulas deterministic and colors readable. To change tile dimensions, update both canvases, coordinate validation, mirror math, repeat geometry and ASCII dimensions together. Add persistence only as a separately designed standalone feature; the gallery demo uses session memory.

## Known limits

Binary 16x16 tiles; three ink palettes; ASCII text output only. No image import/export, layers, persistent saves, collaborative editing or AI generation. Clipboard access can be denied by the sandbox; Select ASCII provides manual copying. Pixel-level pointer targets are small on narrow screens; keyboard and explicit row/column stamping provide precise alternatives.
