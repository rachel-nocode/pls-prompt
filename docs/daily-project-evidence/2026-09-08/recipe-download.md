# Curve Cabinet

Shape a motion curve. Compare the feel. Keep the CSS.

Recipe version: daily-curve-cabinet-v1
Tool: Codex · GPT-6 Astra (High)

## Before you start

Open an empty folder in Codex. Paste Step 1 and then Step 2 in the same task. Open curve-cabinet.html in a modern browser or serve it with a static server. No packages, keys, accounts, paid services or image assets are required. PLS PROMPT adds its own separate gallery and recipe download.

## 1. Build Curve Cabinet

Create curve-cabinet.html: a complete standalone cubic-Bezier CSS easing workshop with inline HTML, CSS and JavaScript. No libraries, external assets, storage, network, accounts, audio, eval or forms. Include viewport meta and CSP meta: default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data:; connect-src 'none'. It must work in an opaque-origin iframe sandbox='allow-scripts'. After initialization send window.parent.postMessage({type:'pls-demo-ready'}, '*').

Visual thesis: a compact near-black motion instrument, with a large square Cartesian curve graph left and a right-side motion comparison bench. Canvas #080808; surfaces #111111; hairlines #383838; controls #777777 borders; text #f2f2f2 and secondary #b8b8b8. Condensed system sans uppercase CURVE CABINET title and system monospace interface. Subtitle: Shape a motion curve. Compare the feel. Keep the CSS. Functional graph/markers use mint #a8ebcb and amber #edc583; controls stay grayscale. Use restrained ASCII +---+ dividers, fine gridlines, rounded 12px graph/bench surfaces and ample padding. Desktop two columns, below 760px stack graph, settings and comparison; useful controls and results immediately visible. Body 16px, controls at least 14px in rem, ordinary buttons and draggable handles at least 44x44px. Text-relative auto-fit fields must reflow at 320px and 200% root text without clipping. No decorative animation.

Core math: endpoints P0=(0,0), P3=(1,1), editable P1=(x1,y1), P2=(x2,y2), all coordinates constrained to [0,1]. Cubic coordinate B(t,a,b)=3*(1-t)^2*t*a + 3*(1-t)*t^2*b + t^3. Given elapsed fraction u, solve B(t,x1,x2)=u with 40 iterations of bisection and return B(t,y1,y2). Return exact 0/1 at endpoints. Do NOT substitute t=u; x1>x2 remains valid. Round user-edited coordinates to 2 decimals. Duration integer 200..3000 milliseconds in increments of 100.

Initial preset Ease=(0.25,0.10,0.25,1), duration=1200, elapsed=0.5, paused. Other exact presets: Linear=(0,0,1,1), Glide=(0.16,1,0.30,1), S-curve=(0.65,0,0.35,1). Preset buttons show aria-pressed based on matching committed coordinates; otherwise show Custom. Applying any curve or duration change pauses animation and preserves current elapsed fraction.

Graph maps elapsed x left-to-right, eased progress y bottom-to-top. Use SVG for grid, diagonal linear reference, cubic path, two tangent lines and current sample dot. SVG is a data visualization, not artwork. Put graph inside a padded square surface so endpoint handles fit inside the page. Overlay two real numbered button handles at corresponding P1/P2 positions; accessible names identify control point and coordinates. Button handles support primary mouse/pen/touch drag with pointer capture, same-pointer moves only, coordinate mapping through plot bounding rect, clamp and round; ignore secondary buttons/pointers. Retain capture until pointerup/cancel/lost capture. Dragging updates curve, fields, output, sample and comparison immediately, pauses animation and preserves elapsed. Scope touch-action:none to handles; page elsewhere scrolls. Handles accept ArrowLeft/Right to move x by .01, ArrowUp/Down y by .01; Shift uses .1; clamp/round; prevent default only handled arrows; retain focus. No global keyboard traps. Show instructions and axis meanings.

Provide labeled number inputs X1,Y1,X2,Y2 and Duration (ms), plus Apply values. Applying uses all five fields atomically: reject blank, nonfinite, out-of-range values; duration must be an integer multiple of 100. Invalid apply pauses but leaves committed curve, duration, sample, preset and export unchanged, preserves entered text, sets aria-invalid on bad fields and announces a readable correction. Valid apply rounds coordinates to two decimals, normalizes fields, clears invalid states and updates everything. Editing fields alone must not affect committed state or animation. Handle/preset/reset actions replace pending field text with current valid state.

Comparison bench: two horizontal lanes labeled Your curve and Linear, each with a square marker whose left percentage is based on a full-width position wrapper ending one marker-width before track edge so endpoints stay inside. Your curve marker uses eased progress, Linear uses elapsed. Both share the same duration/time. Text outputs expose elapsed percent, eased percent and signed percentage-point lead (eased minus elapsed), rounded to one decimal. Graph sample dot is (elapsed,eased). Add a labeled Timeline range input min=0,max=1000,step=1, initially 500; input scrubs elapsed and pauses.

Play resumes from current fraction or restarts at 0 if complete; Pause freezes fraction; Replay starts at 0 and plays; Reset cabinet restores Ease/1200/50%/paused, clears input errors and pending drag, updates all fields/output. Use requestAnimationFrame and timestamp-based elapsed so speed does not depend on frame rate; exactly stop at 100%, no loop, no autoplay. Maintain at most one RAF; cancel it on pause, reset, curve changes, scrubbing and document hidden. Returning visible must stay paused. Reflect state in visible Paused/Playing/Complete text and Play/Pause label. Respect prefers-reduced-motion initially and dynamically: pause when enabled, disable Play and Replay, show Reduced motion: use the timeline. Scrubbing, curve editing and reset remain available. Turning preference off does not autoplay. Status is aria-live polite for actions/errors, not animation frame updates.

Output is a labeled read-only textarea containing exactly two CSS declarations on separate lines: transition-duration: 1200ms; and transition-timing-function: cubic-bezier(0.25, 0.1, 0.25, 1); for initial state. Values always reflect committed curve and duration; canonical numbers have no unnecessary trailing zeros. Add Select CSS (focus and select whole output) and Copy CSS: guarded navigator.clipboard.writeText then guarded document.execCommand('copy') fallback; confirm only actual success, otherwise say Copy unavailable. Use Select CSS and your browser copy command. No download inside sandbox; host supplies recipe separately. Display limitation: Session only. Coordinates stay between 0 and 1; no overshoot or spring physics. CSS sets timing, not what property moves. Use inert textContent/value for dynamic text.

Confirm lane positions, sample dot, percentage-point lead, current-preset state and canonical CSS match committed math. Test valid coordinate/duration apply and invalid blank, NaN-like input, -0.1,1.1,duration 250/199/3100; invalid apply keeps prior curve/duration/export and entered values. Verify graph drag clamp and rounding, mouse and touch emulation, pointer termination, secondary-pointer rejection, arrow increments .01/Shift .1, edge clamps and focus. Verify Play/Pause/resume/Replay/completion, changing curve during play, timeline scrub stopping play, complete reset, hidden-document pause and no auto-resume. Test reduced-motion enabled at start and dynamically; no animation and scrubbing works. Check copy success/denial with explicit injected API branches and Select CSS selection; do not claim real permissions from injected tests. Inspect 320,375,768,1024,1440,1600 widths and 200% root text; repair overflow/clipped fields/handle edges. Capture real initial and changed-curve screenshots. Separately rebuild from this pack in an empty directory without original code or screenshots and verify those behaviors; record actual model, repairs and coverage honestly. Keep this as a consolidated build-and-verification pack rather than a one-shot guarantee.

## Make it yours

Change preset control points or the two marker colors. Replace the comparison markers with your own property preview while preserving the shared elapsed clock and Bezier inversion. To support overshoot, redesign graph bounds, coordinate validation and output metrics together. Add persistence only as an explicitly designed standalone feature.

## Known limits

Session memory only; coordinates limited to 0..1, so no overshoot, springs, CSS import or saved curves. Export sets duration and timing function; you choose the animated property separately. Clipboard permissions vary; Select CSS supports manual copying. Reduced-motion uses manual scrubbing. This is a consolidated prompt pack, not a verbatim transcript or one-shot guarantee.
