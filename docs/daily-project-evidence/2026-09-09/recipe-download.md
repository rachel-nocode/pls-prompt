# Chance Drawer

Predict a token draw. Compare exact odds with thousands of samples.

Recipe version: daily-chance-drawer-v1
Tool: Codex · GPT-6 Astra (High)

## Before you start

Open an empty directory in Codex. Paste Step 1, then Step 2 in the same task. Open chance-drawer.html in a modern browser or serve it with a static server. No packages, accounts, keys, images or paid services are required. PLS PROMPT supplies separate gallery framing and recipe download.

Skip zero-mass states; no factorials, Monte Carlo approximations for exact probability, or impossible negative paths. Event sums distribution for k===target, k>=target or k<=target. ## Make it yours

Change token colors and preset experiments while retaining visible A/B labels and valid count limits. Add an event by updating its acceptance predicate, labels and independent probability checks. Larger bags, draw counts or batch sizes require revisiting numeric precision, rendering cost and caps together.
